# Food Store Manager

Sistema web para gerenciamento de uma loja de alimentos.

A aplicação permite cadastrar produtos e clientes, registrar pedidos.

## Status

🚧 **Em desenvolvimento** — implementação incremental por módulos.

## Funcionalidades

- [ ] Cadastro e gestão de produtos
- [ ] Controle de estoque
- [ ] Cadastro de clientes
- [ ] Registro de pedidos


## Tecnologias

| Camada | Tecnologia |
|--------|-----------|
| Front-end | React |
| Back-end | NodeJs - Express |
| Banco de dados | PostgreSql |
