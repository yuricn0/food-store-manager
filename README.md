# Food Store Manager

Sistema web para gerenciamento de uma loja de alimentos, desenvolvido como trabalho acadêmico da disciplina [NOME DA DISCIPLINA].

A aplicação permite cadastrar produtos e clientes, registrar pedidos e organizar as entregas em lotes (levas), agrupando pedidos por região ou janela de horário para otimizar as rotas do entregador.
